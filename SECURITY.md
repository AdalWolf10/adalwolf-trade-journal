# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's **Security** tab and choose **Report a vulnerability** so the details remain private.

Include the affected page or endpoint, the steps needed to reproduce the issue, and the impact you observed. Do not include real journal data, passwords, session cookies, or private attachment links.
